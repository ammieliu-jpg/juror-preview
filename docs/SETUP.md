# 設定步驟

整合原本的《模組6_表單自動分類_設定步驟.txt》與《模組6_法院端儀表板_設定步驟.txt》，並更新為新的做法（試算表不必公開）。全部免費，約 30 分鐘。

> ⚠ 免費版 Gemini 的資料可能被 Google 用來改進模型，Demo **只能用虛構資料**（例如 C999）。

## 0. 先看效果（什麼都不用設定）

打開 <https://ammieliu-jpg.github.io/juror-preview/court.html> → 按「載入示範資料」。
會看到 17 筆虛構的免除申請，規則判得了的立刻分類，其餘標「待 AI」。

---

## A. 申請 Gemini 免費金鑰

1. 打開 <https://aistudio.google.com>，用**個人** Google 帳號登入。
2. 左邊「Get API key」→「Create API key」，複製金鑰（`AIza` 開頭）。不用綁信用卡。
3. （建議）到 Google Cloud Console →「API 和服務」→「憑證」→ 這把金鑰 →「API 限制」選「Generative Language API」。金鑰外流時，別人也只能拿來呼叫 Gemini。

金鑰不要貼到群組、簡報或 GitHub。

## B. 表單連到試算表

1. 打開「國民法官選任回覆（模擬）」表單 →「回覆」分頁 →「連結至試算表」→ 建立新試算表。
2. 確認試算表裡有「表單回應 1」工作表。題目標題建議和 [DATA_SCHEMA.md](DATA_SCHEMA.md) 一樣（程式用標題找欄位）。
3. **試算表維持「限制」（只有你能看）**，不要再設成「知道連結的任何人」。

## C. 貼上程式

1. 試算表上方「擴充功能」→「Apps Script」。
2. 刪掉編輯器裡原本的內容，貼上 repo 裡 **`apps-script/Code.gs`** 的全部內容（不是 `main.gs`），按 💾 儲存。
   - 直接下載：<https://raw.githubusercontent.com/ammieliu-jpg/juror-preview/main/apps-script/Code.gs>
3. 左邊齒輪「專案設定」→ 最下面「指令碼屬性」→ 新增：

| 屬性 | 值 | 必填 |
|---|---|---|
| `GEMINI_API_KEY` | A 步驟的金鑰 | 是 |
| `DASHBOARD_TOKEN` | 自己想一組 20 字以上的亂碼（給 court.html 用的存取碼） | 要用 court.html 才需要 |
| `GEMINI_MODEL` | 例如 `gemini-2.5-flash` | 否 |
| `NEEDED_PER_CASE` | 到場預測的「選任所需人數」，例如 `40`（依國民法官 6 人、備位人數與預估拒卻人數估算） | 否，沒填暫用 57 |

存取碼可以用這個方法產生：瀏覽器按 F12 → Console → 輸入 `crypto.randomUUID()` → 複製結果。

## D. 授權與觸發條件

1. 編輯器上方函式選單選 `testKey` →「執行」→ 跳出授權視窗：選帳號 →「進階」→「前往（不安全）」→ 允許。
   （程式是自己寫的、沒經過 Google 審核，屬正常現象。）
2. 左邊時鐘「觸發條件」→「新增觸發條件」：
   - 函式：`onFormSubmit`
   - 活動來源：試算表
   - 活動類型：提交表單時
3. 儲存。

## E. 部署成網頁應用程式（給 court.html 讀）

1. 編輯器右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**任何人**。
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

「任何人」只代表網址打得開；沒有正確存取碼就拿不到資料（`doGet` 會先檢查 `DASHBOARD_TOKEN`）。

> 之後每次更新程式，要到「部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署」，網址不變。

## F. 設定法院端儀表板

1. 打開 court.html → 展開「設定」。
2. 資料來源選「Apps Script 網頁應用程式」，貼上 E 的網址和 C 的存取碼 →「儲存並載入」。
   存取碼只存在這個分頁，關掉分頁或開新分頁要重新輸入（存取碼讀得到全部人的說明，所以不存在電腦上）。
3. 不需要填 Gemini 金鑰（分類在 Apps Script 那端完成）。
4. 待審清單裡寫「核對○○後送法官」的，看過實際附件後勾「我已看過附件」。勾選狀態只存在這台電腦。
5. 「產生今日摘要」由程式統計，不使用 AI。

舊做法（公開試算表 CSV）仍保留在「資料來源」選單，只能用虛構資料。

## G. Looker Studio（模組 4）

1. 試算表選單「🤖 AI 免除分類」→「重建儀表板資料」，會產生「回覆資料」「到場預測」兩個工作表。
2. （選填）建立「通知名冊」工作表，貼上候選人編號、案號、通知寄出日，才算得出「未回覆」。
3. Looker Studio → 新增資料來源 → Google 試算表 → 選這份試算表的「回覆資料」與「到場預測」。
   欄位和模組 4 模擬資料一樣，原本做好的圖表換資料來源即可。

## H. 測試

1. 試算表重新整理，上方出現「🤖 AI 免除分類」選單 →「測試 API 金鑰」，出現「金鑰可以用」就成功。
2. 用遊戲最後的「試填一次（示範）」，或直接填表單送一筆：編號 `C999`、申請免除、勾「有重大疾病…」、說明寫「上個月剛做心臟手術」。
   有建立「通知名冊」的話，`C999` 要在名冊裡；不在名冊上的編號不會送 AI，會直接標「需人工確認」。
3. 約 10 秒後，那一列右邊出現 8 個藍色標題的 AI 欄位；需人工確認的標橘色。
4. court.html 按「重新整理」，新的那一列會閃一下。
5. 想一次灌很多測試資料：把模組 4 xlsx「免除申請」的資料貼到表單回應下方（照 B–E 欄），再按「分類所有尚未處理的申請」。超過 5 分鐘會先停，再按一次即可。

## Demo 怎麼擺

- 手機開遊戲（民眾端），筆電開 court.html（法院端），勾「每 20 秒自動更新」。
- 現場用手機送出示範回覆，筆電上的數字和分類就會跟著更新。
- 講稿：「官方調查表不改，我們幫民眾看懂它、幫書記官審完它。民眾回覆前先在預演裡看懂每一題；回覆送進來的瞬間，規則先判掉本人寫明的年齡、在學、法定職業，判不了的才交給 AI，並標出要打電話確認、要核對附件的人。最後准不准仍由法官決定。原型用 Google 表單和 Gemini 免費 API 示範；正式上線時，初篩模組和標註資料接進法院既有的選任系統，AI 改用法院自建的 TAIDE，個資不離開法院。」（導入路徑見 [ARCHITECTURE.md](ARCHITECTURE.md) 第 8 節）

## 常見問題

| 狀況 | 解法 |
|---|---|
| AI 欄位寫「AI 失敗：HTTP 404 …models/…」 | 模型名稱更新了。到 AI Studio 看目前的 Flash 模型名稱，填進指令碼屬性 `GEMINI_MODEL` |
| 寫「API 忙碌中」 | 免費額度每分鐘有上限，等一分鐘再按「分類所有尚未處理的申請」 |
| 授權時出現「This app is blocked」 | 確認程式裡有 `/** @OnlyCurrentDoc */`；仍被擋代表是學校／公司帳號，改用個人 @gmail.com 帳號建立表單副本 |
| 沒有自動跑 | 檢查觸發條件是不是「提交表單時」，以及有沒有完成授權 |
| court.html「存取碼錯誤或尚未設定」 | 確認指令碼屬性 `DASHBOARD_TOKEN` 和儀表板填的一樣；改過程式要部署新版本 |
| court.html「讀取失敗：Failed to fetch」 | 網址要是 `…/exec` 結尾（不是 `…/dev`），且部署時「誰可以存取」選「任何人」 |
| 想讓儀表板重新分類全部 | 按「清除 AI 分類快取」（只影響這台電腦） |
| Demo 結束 | 到指令碼屬性換掉 `DASHBOARD_TOKEN`，舊的存取碼立刻失效 |
| court.html 上方出現「規則版本不一致」 | 改過 `lib/screening.js` 但還沒更新 Apps Script：`npm run build:gs` → 重新貼上 `Code.gs` → 部署新版本 → 選單「分類所有尚未處理的申請」（舊版規則判的會用新規則重判；AI 判的不重跑） |
