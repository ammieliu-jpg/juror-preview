# 這次換你判：AI 國民法官預演室

NextWave 2026 AI法創黑客松參賽原型（非官方，與司法院無關）。

- 線上體驗：開啟 GitHub Pages 後的網址
- 內容：8 個像素場景，從收到選任通知、填調查表、選任宣誓、審前說明、起訴要旨、雙方主張、評議表決到一鍵回覆法院。
- 右下角手機：在瀏覽器內載入小型中文語意模型（bge-small-zh-v1.5，透過 transformers.js），比對司法院國民法官常見問答 42 題並附出處；模型載入前或失敗時，改用關鍵字比對。不需登入、不需伺服器。
- 資料來源：司法院國民法官專區常見問答、司法院公開之模擬法庭教材（臺北地院 111 年度國模交訴字第 1 號，人名改為代號），依政府資料開放授權條款第 1 版使用。
